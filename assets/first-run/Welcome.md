# Welcome to vault-chat

This folder is your vault: plain files on your computer. The agent in the chat can read them, write them, and see
what you have open.

A short tutorial is in the corner of the window (about five minutes). It uses the sample paper in `Welcome/`:

- `Welcome/sample-paper.pdf`: *The Broad Street Pump (London, 1854)*, a three-page explainer with John Snow's cholera map.

Things to try any time:

- Ask about what you are reading: select something (or nothing) and press Cmd+L (Ctrl+L on Windows).
- Change a file in place: select text in a note and press Cmd+K (Ctrl+K on Windows).
- Ask for a tool: "make me a timer", "make me flashcards from this note". It shows up live.
- "start the tutorial" shows the tutorial again. "delete the tutorial" removes it; this file and `Welcome/` stay.
