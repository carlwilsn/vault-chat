# Chat with @file mentions

Open the chat pane (right side — if it's collapsed there's a chevron to expand it). Type `@` and start typing — pick **kant-summary.md** from the dropdown that appears. Then send:

> what does kant mean by "categorical imperative" in plain english?

The agent reads the file and answers. You can `@` multiple files in one message — try `@kant-summary.md @utilitarianism.md compare these two ethical frameworks`.

The agent can also read any file in the vault without an explicit `@`. Just ask:

> what's in this vault?

It'll list the notes. Or:

> summarize all the notes in the `notes/` folder

It'll read each one and give you a synthesis. The agent has Read / Write / Edit / Bash tools — it's the same agent you'd find in Claude Code, but pointed at your vault.
