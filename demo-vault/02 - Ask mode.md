# Ask mode (Ctrl+L)

Same selection trick, different keybind. Select the paragraph below. Press **Ctrl+L**. Ask:

> what's wrong with this argument?

The answer appears in the popover. The file isn't touched. Use this when you want a second opinion, a translation, or an explanation without committing to a change.

---

Anyone who really cared about climate change would never fly. Sarah flew to a conference last month. Therefore Sarah doesn't actually care about climate change.

---

Try follow-ups in the same popover: *"give me a one-line counter"*, *"what's this fallacy called?"*, *"steelman the original argument"*. Each response stays inside the popover so your file stays clean.

The rule of thumb: **Ctrl+K** when you want the file to change, **Ctrl+L** when you just want to think.
