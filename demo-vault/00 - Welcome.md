# Welcome to vault-chat

This is a demo vault — every note here walks you through one feature, hands-on. Read the instruction, do the thing, see what happens. Ten minutes total.

If you haven't set up an API key yet:

1. Click the **gear icon** (top-right titlebar).
2. Grab a free Gemini key from [aistudio.google.com/apikey](https://aistudio.google.com/apikey) — sign in, **Create API key**, copy the value.
3. Paste it into the **Google** field, click **Save**.
4. In the model dropdown at the top of the chat pane (right side), pick **gemini-2.5-flash**. Free tier, no credit card.

Anthropic and OpenAI keys work the same way if you'd rather use Claude or GPT.

When you're ready, open **01 - Inline edit.md** in the file tree on the left.
